# ДИКИЙ КРАЙ

Самостоятельная игра на Godot 4.7.2 Stable: стилизованная 3D-песочница о выживании в лесной долине для Android.


## Первая играбельная версия

- Первое лицо, сенсорный джойстик и свайп-осмотр.
- Стилизованная долина, лес, ручей и деревянный мост.
- Сбор веток, камней и ягод.
- Простая система жажды, сытости, здоровья и выносливости.
- Питьё у ручья, ягоды и создание костра.
- Управление с ПК для проверки: WASD/стрелки, мышь, E — действие, F — съесть ягоду, B — костёр, Shift — бег, Esc — отпустить мышь.

## Сборка APK

Каждый push в ветку `dikiy-kray` запускает GitHub Actions. В успешном запуске скачай артефакт **DIKIY-KRAI-debug-apk**, распакуй ZIP и установи `DIKIY_KRAI.apk` на Android.

Это ранний прототип. Следующие этапы: реальная проверка на телефоне, сохранение мира, доработка инвентаря и взаимодействий, звук, полировка интерфейса.
